# dsh-locale-ru

Русский язык для веб-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

Плагин добавляет **«Русский»** в штатный переключатель языка (Settings → General)
и переводит интерфейс через **официальный API локализации**
(`@deepseek-ai/dsh-client-locale`). Файлы самого Harness не изменяются — форк и
пересборка не нужны, обновления `dsh` настройку не сбивают.

## Чем отличается от других языковых пакетов

Обычный языковой пакет сообщает «100 % перевода», не говоря, **к какой версии
`dsh`** это относится. У Harness стадия _developer preview_: строки добавляются,
переименовываются и удаляются между релизами, и такой процент тихо устаревает —
часть интерфейса просто остаётся английской, и никто этого не замечает.

Здесь покрытие **измеряется против установленной у вас версии**:

```sh
node scripts/drift.mjs
```

Скрипт сам находит установленный `dsh`, сравнивает его строки со словарями и
печатает, что именно ещё не переведено, что устарело и не разошёлся ли
переобъявленный блок пресетов разрешений. Код возврата 1, если есть
непереведённое, — поэтому проверку можно ставить в CI.

## Совместимость

- Текущее состояние измерено против `dsh-v0.1.5-rc.1`: **1198/1198 ключей, 100 %**.
- Пакет — **внешний плагин**, а не встроенный язык ядра: он регистрирует язык и
  словари через публичный API. Гарантии у этих путей разные — встроенный язык
  проходит полный релизный цикл ядра, внешний проверяется против конкретной ревизии.
- После обновления `dsh` запустите `node scripts/drift.mjs` — он покажет, что
  изменилось. Процедура описана в [docs/upstream-sync.md](docs/upstream-sync.md).

## Установка

```sh
dsh plugin --profile web add github:EqOSl1me/dsh-locale-ru
```

Затем **перезапустите `dsh web`** (остановите процесс и запустите заново).

**Проверка за 30 секунд:**

1. Откройте **Settings → General**.
2. В строке **Language** выберите **«Русский»**.
3. Интерфейс сразу переключится: боковая панель покажет «Новая сессия» и «Настройки».
   Выбор сохраняется в `$DSH_HOME/settings.yaml` и переживает перезапуск.

Удаление:

```sh
dsh plugin --profile web remove dsh-locale-ru
```

## Состав репозитория

| Путь | Роль |
|---|---|
| `dict/ru/*.json` | **Исходники перевода** — править нужно только их |
| `lib/client.js` | Собранный бандл (коммитится, чтобы установка не требовала сборки) |
| `index.js` | Host-половина: намеренный no-op, нужна сканеру client-modules |
| `cordis.patch.yml` | Монтаж пакета + русские названия пресетов разрешений |
| `upstream/corpus.json` | Английские строки, извлечённые из `dsh` |
| `upstream/meta.json` | Ревизия, из которой извлечён корпус |
| `scripts/` | `extract`, `build`, `check`, `drift` |

## Разработка

```sh
node scripts/check.mjs          # структура словарей: ключи, плейсхолдеры, пустые строки
node scripts/check.mjs --strict # плюс ошибка на каждый непереведённый ключ
node scripts/drift.mjs          # покрытие против установленного dsh (exit 1 при пробелах)
node scripts/build.mjs          # dict/ru/*.json -> lib/client.js
node scripts/smoke.mjs          # загрузить бандл как браузер и проверить регистрацию
```

Порядок правки перевода:

1. Найдите английскую строку: `node scripts/drift.mjs` покажет недостающие ключи.
2. Отредактируйте `dict/ru/<namespace>.json`.
3. `node scripts/check.mjs` — проверка плейсхолдеров и структуры.
4. `node scripts/build.mjs` — пересобрать бандл.
5. Коммитьте **и** файл словаря, **и** `lib/client.js`.

После обновления `dsh`:

```sh
node scripts/extract.mjs --root <клон deepseek-harness>   # обновить корпус
node scripts/drift.mjs                                    # увидеть, что отстало
```

### Конвенции перевода

- Плейсхолдеры (`{count}`, `{name}`) должны совпадать с английскими — проверяется
  автоматически.
- Клиент различает только `.one` и `.other`, поэтому во множественном числе
  используется форма без согласования: «Сессий: {n}», а не «{n} сессий».
- Продуктовые названия (VS Code, GitKraken, Xcode) и аббревиатуры (HTML, PDF,
  TTFT, TPS) не переводятся.

## Пресеты разрешений

Пресеты (`read-only`/`workspace-write`/`danger-full-access`) не переводятся
словарями: базовый бандл задаёт их без отображаемых имён, и UI показывает
машинные идентификаторы. `cordis.patch.yml` переобъявляет таблицу с русскими
названиями. **Идентификаторы, режим песочницы и правила подтверждений не
меняются** — `/permission <id>` и семантика сессий прежние.

Так как строка патча заменяет конфиг целиком, `drift.mjs` отдельно проверяет,
что ни один пресет из ядра не потерялся.

## Безопасность

- Host-половина (`index.js`) — намеренный no-op.
- **Ноль runtime-зависимостей**: `package.json` не содержит ни одного пакета в
  `dependencies`. Устанавливаемый код — `index.js`, `lib/client.js` и
  `cordis.patch.yml`, их можно прочитать целиком.
- Плагин не обращается к сети, файлам, процессам и учётным данным; не читает и не
  хранит содержимое сессий.
- Файлы Harness не модифицируются — только публичный API внешних плагинов.
- Откат — одна команда (см. «Установка»).
