# Синхронизация с upstream

DeepSeek Harness — _developer preview_: строки интерфейса добавляются,
переименовываются и удаляются между релизами. Этот документ — процедура после
обновления `dsh`.

## 1. Узнать установленную версию

```sh
node scripts/drift.mjs
```

Скрипт сам находит установленный `dsh` и печатает две строки:

```
  installed dsh : 0.1.5-rc.1  (<путь>)
  corpus from   : dsh-v0.1.5-rc.1
```

**Если версии разошлись** — корпус устарел, цифры покрытия недостоверны.
Переходите к шагу 2.

## 2. Обновить корпус

```sh
git clone --depth 1 --branch <тег или ветка> https://github.com/deepseek-ai/deepseek-harness.git /tmp/harness
node scripts/extract.mjs --root /tmp/harness
```

`extract.mjs` обходит клон, находит каждый вызов `locale.register(...)` и
извлекает словари `en`/`zh` динамическим импортом. Если пакет импортировать
нельзя (в голом клоне нет части зависимостей), словарь разбирается текстуально, а
случай попадает в `upstream/report.json`. Скрипт заодно записывает
`upstream/meta.json` — ревизию, из которой извлечён корпус.

## 3. Посмотреть, что отстало

```sh
node scripts/drift.mjs
```

Вывод делится на три части:

- **Namespaces with NO Russian at all** — целые разделы интерфейса на английском.
- **Partially translated** — конкретные недостающие ключи.
- **Stale keys** — ключи в словарях, которых больше нет upstream: их можно удалить.

Отдельно проверяются **пресеты разрешений**: `cordis.patch.yml` переобъявляет
таблицу пресетов целиком, поэтому пресет, добавленный upstream, был бы скрыт от
пользователей. `drift.mjs` сообщает об этом как о MISSING.

## 4. Перевести и собрать

```sh
# правим dict/ru/<namespace>.json
node scripts/check.mjs      # структура, плейсхолдеры
node scripts/build.mjs      # -> lib/client.js
node scripts/drift.mjs      # должно быть 100 %
```

Если upstream переименовал namespace, создайте файл с новым именем и удалите
старый: `check.mjs` сообщит о несуществующем namespace как об ошибке.

## 5. Проверить вживую

Перезапустите `dsh web`, откройте Settings → General и убедитесь, что «Русский»
на месте и выбор работает. Скрипты проверяют структуру, но не то, как строки
выглядят в интерфейсе.

## Автоматизация

`.github/workflows/upstream-drift.yml` делает шаги 2–3 раз в неделю и открывает
issue со списком изменений. Ручной прогон — через `workflow_dispatch`.
